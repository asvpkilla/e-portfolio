# 🌐 e-Portfolio — Interactive Electronic Resume

**Status:** Active Development 🚧  

This repo contains my personal **interactive e-portfolio**, built as a modern electronic resume and professional showcase using core web technologies. 

---

## 📌 Overview

The e-portfolio serves as a centralized hub for:
- Professional background
- Technical skills
- Projects and labs
- Contact information

The site is intentionally lightweight and framework-free to highlight strong **HTML, CSS, and frontend fundamentals**.

---

## 🚀 Current Features

### 🏁 Splash / Landing Page
- Responsive layout using **HTML5 & CSS3**
- Primary navigation entry point
- Optimized for desktop and mobile devices
- Polished UI with subtle visual effects

### 🧠 Easter Eggs
- Hidden interactive elements triggered by user actions
- Demonstrates event-driven behavior and CSS animations
- Designed to reward exploration without impacting usability

### 📄 Implemented Pages

| Page | Description |
|------|------------|
| `index.html` | Home |
| `about.html` | Professional Knowledge |
| `projects.html` | Project Discovery |
| `resume.html` | ePortfolio |
| `contact.html` | Contact Info |
